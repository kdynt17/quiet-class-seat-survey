# 우리 반 자리 투표

27명이 앉고 싶은 자리의 1~27순위를 정하면, 모든 학생의 희망 순위 합이 가장 작아지도록 중복 없는 자리를 계산하는 정적 웹페이지입니다.

## 사용 순서

1. 응답자 번호를 고릅니다.
2. 가장 앉고 싶은 자리부터 27개 책상을 차례로 누릅니다.
3. `내 응답 저장하기`를 누르고 다음 학생이 같은 기기에서 이어서 참여합니다.
4. 결과 화면에서 인기 자리, 참여 현황, 전체 선호도를 반영한 자동 배치를 확인합니다.

## 데이터베이스 없는 보관 방식

- 응답은 현재 브라우저의 `localStorage`에 저장됩니다.
- 27명이 **같은 기기와 같은 브라우저**에서 차례로 응답해야 한곳에 집계됩니다.
- 결과 화면에서 결과 PNG 이미지를 저장하거나, 결과 요약이 들어간 이메일 초안을 열 수 있습니다.
- 브라우저 보안상 이미지 파일은 이메일에 직접 첨부해야 하며 최종 전송도 사용자가 누릅니다.
- `JSON 백업`과 `백업 복원`으로 데이터를 다른 기기에 옮기거나 복구할 수 있습니다.
- 학생 이름 대신 번호만 저장합니다.

## 자동 배치 기준

헝가리안 알고리즘으로 각 학생에게 서로 다른 자리 하나를 배정하면서, 배정된 자리의 희망 순위 합을 최소화합니다. 아직 응답하지 않은 학생이 있으면 임시 결과로 표시합니다.

## GitHub Pages

저장소의 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/root`를 선택하면 게시할 수 있습니다.
