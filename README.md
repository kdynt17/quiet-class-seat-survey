# 조용한 우리 반

27명의 자리 기피도 순위와 소음 투표를 모아 임시 자리 배치 결과를 만드는 정적 웹페이지입니다.

## 사용 순서

1. 응답자 번호를 고릅니다.
2. 가장 싫은 자리부터 27개 책상을 차례로 누릅니다.
3. 최근 수업에서 가장 자주 큰 소리를 낸 학생 한 명을 선택합니다.
4. 응답을 저장하고 다음 학생이 같은 기기에서 이어서 참여합니다.
5. 결과 화면에서 자리 기피도, 소음 투표, 자동 배치 결과를 확인합니다.

## 데이터 보관

- 응답은 현재 브라우저의 `localStorage`에 저장됩니다.
- 27명이 **같은 기기와 같은 브라우저**에서 차례로 응답해야 한곳에 집계됩니다.
- 결과 화면의 `JSON 백업`과 `백업 복원`으로 데이터를 옮기거나 복구할 수 있습니다.
- 학생 이름 대신 번호만 저장합니다.

## 자동 배치 기준

소음 투표가 많은 학생부터 자리 기피도 순위가 높은 자리에 차례로 대응합니다. 동점은 학생 번호 또는 자리 번호가 빠른 순서로 정렬합니다. 이 결과는 임시안이며, 시력·키·학습 지원·학생 관계를 교사가 함께 고려해 최종 확정해야 합니다.

## GitHub Pages

저장소의 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/root`를 선택하면 게시할 수 있습니다.
